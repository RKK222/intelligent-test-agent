Memory data-plane release license inventory
===========================================

This file is an operator index, not a replacement for the SPDX SBOM files
generated for every delivered image.

- Mem0 OSS (`mem0ai==2.0.17`): Apache License 2.0.
- BAAI/bge-small-zh-v1.5 model: MIT license as declared by the upstream model card.
- pgvector 0.8.1: PostgreSQL License.
- Nginx 1.27.2: BSD-2-Clause license.
- Python and OS dependencies: see `sbom/*.spdx.json`; those inventories are
  generated from the exact docker-loadable tar files in the same release.

The model revision, runtime normalization contract, and embedding dimension are
locked in `MODEL-IDENTITY.json`. The exact source locks and Alembic migrations
used to build the images are included under `source/` and `alembic/`.
