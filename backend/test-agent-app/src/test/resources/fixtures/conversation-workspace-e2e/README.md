# 开源项目质量验证工作空间

本目录是对话与工作空间端到端测试数据的本地轻量副本。应用版本库配置指向公开开源项目，
但造数过程不会下载远端源码；这样可以稳定验证应用、版本库、工作空间、文档树和历史对话，
且不受公网速度影响。

## 建议验收路径

1. 在应用下拉中选择“E2E 开源项目质量验证”。
2. 打开“Spring PetClinic 退款验证工作空间 / e2e-20260812”。
3. 在文件树查看 `requirements/`、`docs/design/`、`.opencode/agents/` 和 `.opencode/skills/`。
4. 在历史对话中搜索 `[E2E]`，依次检查普通对话、需求、详细设计、Skill、Agent、Permission 和 Subagent 场景。

fixture 只用于本地测试环境，不应发布到真实应用仓库。
