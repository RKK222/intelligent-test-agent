# 分享会话用户消息两色设计

## 目标

用户消息气泡只保留两种颜色，并始终以当前查看者为判断基准：

- 当前用户自己发送的消息使用 `#B2EDDF`。
- 当前用户看到的所有其他人消息统一使用 `#9A8EDE`。
- 两种消息气泡都不显示边框。

发送人姓名规则不变：自己的消息不显示姓名，其他人的消息显示姓名。

## 实现边界

只修改 `@test-agent/agent-chat` 中既有的统一消息外观解析函数，不调整后端归因字段、分享权限、消息 DTO、全局主题变量或其他卡片样式。普通工作台和分享工作台继续复用同一解析函数，避免两套颜色规则漂移。

历史消息缺少发送人归因时继续按自己的消息展示，即使用 `#B2EDDF`、无边框且不显示姓名，保持旧数据兼容。

## 样式契约

| 消息关系 | 背景色 | 边框 | 姓名 |
|---|---|---|---|
| 自己发送 | `#B2EDDF` | 无 | 不显示 |
| 其他人发送 | `#9A8EDE` | 无 | 显示 |
| 缺少历史归因 | `#B2EDDF` | 无 | 不显示 |

文字继续使用现有前景色，不引入按用户哈希生成色相的逻辑。

## 测试与验收

先修改消息外观单元测试并确认其因旧的哈希配色而失败，再用最小实现使其通过。测试覆盖自己、其他人和缺少归因三种情况，并明确断言背景色和 `border: none`。

随后执行 agent-chat 定向测试、前端全量 Vitest、workspace 类型检查和生产构建。该调整不涉及 HTTP API、事件、数据库迁移、安全策略或 OpenCode。
