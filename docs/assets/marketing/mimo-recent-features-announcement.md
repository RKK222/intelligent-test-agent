# MIMO 测试智能体近期功能介绍

最近，MIMO 测试智能体工作台上线了几项实用功能：

- 会话可以分享给同事了。发起人可设置 1 天、3 天或 7 天有效期，并逐人选择“只读”或“可对话”。大家在同一条会话里查看结果、继续处理任务，页面会标明消息是谁发的。
- 批量案例设计更省事。一次最多选择 50 个需求子条目，每个子条目单独建立会话，可立即执行，也可安排到夜间；失败项支持单独或批量重试。
- 常用会话可以置顶。任务结果不合适时，最后一条消息还可以“撤销重发”，不用重新整理上下文再发一遍。
- 测试资料跳转支持多选。在文件树里选中“测试设计”或“测试执行”资料，点击纸飞机，就能把多份文件带到关联的外部页面；路径里的子条目编号也会一起传递。

这些功能已经可以在工作台中使用。操作不熟时，点击顶部书本图标打开用户手册，按功能名称搜索即可。
