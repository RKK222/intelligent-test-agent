# MIMO 测试智能体近期功能更新

近期，MIMO 测试智能体工作台新增了以下功能：

- 已有会话可以分享给指定同事。分享有效期可设为 1 天、3 天或 7 天，并可按人员配置“只读”或“可对话”权限。参与者可以在同一会话中查看结果，具备权限的成员可以继续处理任务；页面会记录实际操作人。
- 批量案例设计一次最多选择 50 个需求子条目，每个子条目单独创建会话，可立即执行，也可安排在夜间执行。创建失败的条目可以单独或批量重试。
- 常用会话可以置顶。最后一条消息的执行结果需要调整时，可以使用“撤销重发”重新执行。
- 文件树可以多选“测试设计”或“测试执行”资料，并通过纸飞机按钮带到关联的外部页面。符合规则的子条目编号会一并传递。

以上功能已在工作台开放。具体入口和使用限制可在顶部书本图标打开的用户手册中查询。
