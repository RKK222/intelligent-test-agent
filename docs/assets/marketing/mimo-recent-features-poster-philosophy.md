# 流动的能力

这是一种把“能力”看作流体的视觉哲学：它从一个人的工作台出发，经过协作、记忆与本地执行，最后汇入可复用的公共能力场。画面不解释流程，而是用一条贯穿全幅的光带、四个有秩序的节点和不断回返的细线，表达知识如何被传递、沉淀、调用，再次变成行动。

空间采用暖白画布与冰蓝、靛青、薄荷绿、紫罗兰的受控渐变，像一张在日光下展开的系统星图。大面积留白承担呼吸，细密的网格、坐标、短标签和微小刻度构成“可观测”的秩序；局部截取真实界面，让抽象的能力流在产品证据中落地。颜色不是装饰，而是四种不同的跃迁状态：分享是蓝色连接，记忆是青色沉淀，客户端是绿色落地，能力库是紫色聚合。

构图以不对称的垂直轴建立张力：上方用一个克制而有重量的主标题定锚，中部让四个模块像轨道上的卫星围绕核心运行，下方用细线和短句把视线收束到产品入口。文字只保留必要的名字与承诺，成为图形的一部分；长解释被压缩为节奏明确的短语，让视觉关系先于阅读发生。

所有边缘、圆角、阴影、截图裁切和字距都必须经过反复校准，呈现出经过大量时间打磨的精密感。每一条连接线都像是手工校正过的测量线，每一块色面都像在深夜反复比对后的结果。最终作品应当是细节克制、层次丰富、执行严谨的专业海报：第一眼有气势，第二眼能读懂，停留更久还能发现系统性与人手工艺的痕迹。
