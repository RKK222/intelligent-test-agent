# 好事发生

这是一种以留白和跃迁为核心的视觉哲学。画面把每一次有效的工作想象成一颗被轻轻抛出的石子：它不是停在原地，而是在更大的水面上留下四次清晰、彼此关联的涟漪。主视觉只保留一条宽阔的流线与四个独立而亲近的落点，让关系先被看见，信息随后才被读懂。

空间使用奶白、雾蓝和极浅的薰衣草色，像晴天的纸张。深靛蓝承担文字的重量，电光蓝、薄荷绿和柔紫只在关键动作处出现，形成少而准的色彩记忆。截图不是技术证据墙，而是被珍视的产品片段：经过精确裁切、柔和阴影和从容留白后，像一张张放在桌上的即时拍立得。

构图拒绝密集网格和功能清单。上方是一句能被远处读到的主张，中部一组大小有别的视觉卡片沿着流线展开，下方只用一句安静的收束。每张卡片只说一件事，用很少的文字、明确的色块和一个可感知的界面细节表达它的性格；所有尺度关系都要经过严谨推敲，形成自然却绝不随意的节奏。

材质要轻，边缘要干净，阴影要像纸张悬起时才会出现的空气感。每一个圆角、留白、字体层级与截图比例都应体现反复打磨的手工精度；删掉任何只是在填空的装饰，把注意力留给真正重要的形、色与呼吸。最终成品应像一本优秀产品画册的封面：极其克制，却能让人一眼记住。
