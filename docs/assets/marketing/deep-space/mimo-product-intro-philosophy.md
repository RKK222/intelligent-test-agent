# 星轨共生

“星轨共生”以深海般的留白承载缓慢生长的能力网络。空间不被填满，而是被路径、节点与光晕精确组织：每一个模块都像独立天体，各自清晰，又通过细密轨道形成可感知的协作关系。文字只承担锚点作用，核心信息由距离、方向、聚合与扩散来表达。

色彩从近黑蓝过渡到电光青、群青与克制的紫，偶尔以薄荷绿提示“完成”和“流动”。材质既像玻璃仪器，也像夜间运行的工程控制台；透明层级、微弱噪点与冷色反射需要经过反复校准，让作品呈现出顶尖设计师历经无数次调整后的精确质感。

尺度遵循“恒星—卫星—星尘”的节奏：大标题和核心界面构成重力中心，小标签与编号沿轨道分布，细小数据点提供连续脉搏。不同尺度之间必须有充分呼吸，任何复杂度都通过秩序消化；每一处对齐、间距与视觉重量都体现 painstaking attention 和 master-level execution。

构图是一条向下展开的能力航线。上半段建立任务持续推进的引力，中段展示工作空间、并行任务、智能协作与后台运行的轨迹，后半段让资产发布、跨应用引用和开放扩展汇聚成生态。信息不靠长段解释，而靠重复的连线、可追溯的编号和由单点向网络扩展的空间隐喻自然显现。

最终作品必须像一件被长期打磨的系统图谱：真实界面是证据，抽象轨道是想象，二者在同一视觉语言中无缝衔接。所有光效保持克制，所有细节都服务于清晰度；整体应当呈现深厚专业经验、无数小时手工推敲和近乎苛刻的完成度。
