# 邮件正文

为落实数智工软 AI-SDC 行动规划，杭州产品部建设了 MIMO 测试智能体工作台，现诚邀各产品部结合实际业务场景使用并参与能力共建。

【工具简介】

MIMO 测试智能体工作台基于灵犀Code通用智能体底座建设，面向测试人员日常工作。在项目工作区引入需求、设计、代码和测试资料后，可按需组建专业 Agent Team，完成设计分析、案例生成和案例审核，并开展测试执行（接口与 UI）、应用代码白盒分析等工作。同时支持晚间任务与长程任务：测试人员可在白天与 Agent 协商确认任务目标，约定晚间执行时间后，任务自动接续执行。任务过程与产物统一留存，便于复核和复用。

【核心亮点】

1. 测试 Agent Team：设计分析、案例生成和案例审核等多 Agent 分工协同，完成测试范围分析、结构化案例生成和独立审核。同时，围绕 JSP 调用分析、SLB 排查、验收案例增量生成、异步文件处理等场景，已有应用特色技能实践，形成可复用的应用能力。
2. 长任务与定时接续：在已有对话中确认任务和执行时间后，可在约定时段自动接续执行，无需重新发起任务或重复补充上下文；已尝试完成 50 个 JSP 入口菜单调用链路分析，单次持续执行 4 小时以上。

【能力共建、共享与扩展】

- 各产品部从真实业务场景出发，提供任务、业务规则、样例和验收标准；杭州产品部协助将成熟方法封装为可执行能力。
- 成熟 Agent、Skill、规约、模板和工具连接可按权限跨项目共享，也可快速复用 SkillHub 既有 Skill；后续可通过 MCP / Tool 接入更多测试平台和业务系统。
