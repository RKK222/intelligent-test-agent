为推进数智工软 AI-SDC 行动落地，进一步探索 AI 在测试场景中的规模化应用，MIMO 测试智能体工作台现面向各产品赋能团队开放使用与场景共建。诚邀大家结合实际业务任务体验平台能力，共同把一线测试经验沉淀为可复用、可共享、可持续演进的智能资产。

【工具简介】

MIMO 测试智能体是一站式智能测试工作台。它不只是一个对话窗口，而是把工作空间、任务执行、智能体协作、后台调度、知识资产和能力市场连接在一起，让测试任务在有人操作和无人值守时都能持续推进，并保留清晰、可追溯的过程与结果。

【适用用户】

本工具主要面向测试经理、测试分析与设计人员、测试执行人员、质量工程师，以及参与需求—研发—测试协同的产品和研发团队。

一是复杂测试任务。可在独立工作空间中引入需求、设计、代码和测试资料，由智能体结合当前项目上下文完成分析、设计、评审和产物落盘。

二是多任务并行。不同工作空间和任务可独立推进，用户可随时切换查看进度，减少串行排队和页面值守。

三是多角色协作。主智能体可拆解复杂任务，调度子智能体分工执行，并统一汇总阶段结果。

四是后台与夜间执行。任务离开当前页面后仍可持续运行，并支持在可用时段内预约夜间任务，第二天继续查看进度和结果。

五是团队能力复用。成熟的 Agent、Skill 与知识资产可沉淀、发布、引用和更新，让已有成果直接服务新的项目任务。

【核心亮点】

1. 独立工作空间：应用、版本、文件、对话和 Git 变更按工作空间组织，项目上下文清晰隔离；输入、过程和产物均可回看、可追溯。

2. 多任务并行推进：多个任务可在各自空间独立运行，进度与结果互不干扰；用户不必等待上一项完成后再启动下一项。

3. 子智能体协同：主智能体负责任务理解与拆解，子智能体按角色分工执行，阶段成果自动汇聚，复杂任务协作链路更加清晰。

4. 后台与定时运行：任务可在后台持续推进，并支持夜间任务的查看、改期与取消；执行状态、待处理问题和完成结果都有明确提示。

5. 跨资产库引用：可检索并引用既有知识资产，把成熟成果带入当前工作区；来源、版本和引用关系保持清晰，减少重复整理。

6. Agent / Skill / MCP / Tool Hub：统一呈现可复用 Agent、Skill 和已加载的 MCP、Tool。具备权限的团队可发布、引用、更新 Agent 与 Skill，并在个人工作区完成冲突处理和 Git 提交。

【能力共建、共享与扩展】

MIMO 希望沉淀的不只是一次任务结果，更是一套可以持续生长的团队能力：

- 共建：欢迎各团队把高频场景、专业方法、操作规范和评价标准沉淀为 Agent 或 Skill，与平台团队共同打磨。
- 共享：成熟能力可发布到 Hub，被其他应用发现和引用；原创应用、来源版本、发布状态和更新关系清晰可见。
- 扩展：平台以 Agent、Skill、MCP、Tool 组织能力，可围绕新的测试对象、工具链和业务系统持续扩展；新增能力进入统一工作台和运行链路，不需要再搭建彼此割裂的独立入口。

后续我们将结合共建场景持续完善能力目录、使用体验和评价机制，让个人经验更容易沉淀，让团队成果更容易复用，让优秀能力在更多项目中产生价值。
