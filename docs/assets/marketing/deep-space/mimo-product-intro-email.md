# 邮件正文

各位同事：

为落实数智工软 AI-SDC 行动规划，杭州产品部建设了 MIMO 测试智能体工作台，现诚邀各产品部结合实际业务场景使用并参与能力共建。

【工具简介】

工作台面向测试人员日常工作。在项目工作区引入需求、设计、代码和测试资料后，可直接 @ 对应 Agent，分别开展测试分析、案例设计、接口测试执行和应用专项任务，并保留相关任务产物。

【核心亮点】

1. 现有 Agent 可直接使用：测试设计 Agent 可开展分析、案例生成和审核；测试执行 Agent 当前支持接口测试执行；JSP 调用分析、SLB 排查、验收案例增量生成、异步文件处理 4 个应用 Agent 已就绪。
2. 项目资料集中管理：需求、设计、代码和测试资料可在同一项目工作区引用，各类任务产物分别留存，减少重复查找和上下文切换。
3. 复杂任务持续推进：多个 subagent 可并行协作，任务支持后台运行和定时执行，过程与结果可查看、可复核、可追溯。

【能力共建、共享与扩展】

- 各产品部提供真实任务、业务规则、样例和验收标准，杭州产品部协助完成能力设计、工具接入和验证。
- 成熟 Agent、Skill、规约、模板和工具连接可按权限跨项目共享，也可快速复用 SkillHub 既有 Skill；后续可通过 MCP / Tool 接入新的测试平台和业务系统。已有 UI 测试执行能力尚未与工作台打通，可作为后续能力接入方向。
