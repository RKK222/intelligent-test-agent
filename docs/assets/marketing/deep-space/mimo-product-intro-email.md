# 邮件正文

各位同事：

为落实数智工软 AI-SDC 行动规划，杭州产品部建设了 MIMO 测试智能体工作台，现诚邀各产品部结合实际业务场景使用并参与能力共建。

【工具简介】

工作台面向测试人员日常工作。在项目工作区引入需求、设计、代码和测试资料后，可按需组建测试设计 Agent Team，完成测试设计，再开展接口与 UI 测试执行、应用专项分析、长任务和定时接续，并保留相关任务产物。

【核心亮点】

1. 测试设计 Agent Team：设计分析、案例生成和案例审核三个 Agent 分工协同，完成测试范围分析、结构化案例生成和独立审核。
2. 测试执行覆盖接口与 UI：测试执行 Agent 支持接口测试和 UI 测试；JSP 调用分析、SLB 排查、验收案例增量生成、异步文件处理 4 个应用 Agent 已有实践，可按对应场景使用。
3. 长任务与定时接续：在已有对话中确认任务和执行时间后，可在约定时段自动接续执行，无需重新发起任务或重复补充上下文；已完成 50 个 JSP 入口菜单调用链路分析，单次持续执行 4 小时以上。

【能力共建、共享与扩展】

- 各产品部从真实业务场景出发，提供任务、业务规则、样例和验收标准；杭州产品部协助将成熟方法封装为可执行能力。
- 成熟 Agent、Skill、规约、模板和工具连接可按权限跨项目共享，也可按需复用 SkillHub 既有 Skill；后续可通过 MCP / Tool 接入更多测试平台和业务系统。
