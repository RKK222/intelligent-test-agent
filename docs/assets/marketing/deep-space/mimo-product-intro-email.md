【工具简介】

工作台面向测试人员日常工作。在项目工作区引入需求、设计、代码和测试资料后，可直接 @ 对应 Agent，开展 Agent Team 测试设计、接口与 UI 测试执行、应用专项分析、长任务和定时任务，并保留相关任务产物。

【核心亮点】

1. Agent Team 协同设计：设计分析、案例生成、Review 三个 Agent 组成 Agent Team，分工完成测试范围分析、结构化案例生成和独立审核。
2. 测试执行覆盖接口与 UI：测试执行 Agent 支持接口测试和 UI 测试；JSP 调用分析、SLB 排查、验收案例增量生成、异步文件处理 4 个应用 Agent 也可直接使用。
3. 长任务与定时执行：已完成单次超过 4 小时的长任务，深度分析 50 个 JSP 入口菜单调用链路并完成复核；也可白天在已有对话中确认任务目标，晚上按约定时间自动执行。

【能力共建、共享与扩展】
