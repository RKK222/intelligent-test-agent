# 技能名称

用一段话说明用户价值、核心产物和完成标准。

## 适用范围

- 适用：列出应处理的任务。
- 不适用：列出交给其他技能或需要人工处理的任务。

## 输入检查

1. 读取用户提供的材料和目标目录。
2. 复用已有事实，不重复追问。
3. 只有缺失信息会显著改变结果时才询问。

## 执行流程

1. 定位现有实现和约束。
2. 完成任务核心步骤。
3. 处理失败、缺失输入和权限边界。
4. 写入约定产物。
5. 运行最相关验证。

## 输出格式

明确列出最终响应或文件结构，删除所有示例占位内容后再交付。

## 完成门禁

- 需求范围已覆盖；
- 所有引用资源存在；
- 实际验证结果已记录；
- 未完成项和风险已明确说明。
