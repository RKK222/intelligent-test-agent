# 混沌案例库

按系统类型分类。每个案例包含案例 ID、故障分类、注入方法和关联故障类型。

## distributed（分布式系统）

| 案例ID | 故障分类 | 注入方法 | 关联故障类型 |
|--------|---------|---------|-------------|
| chaos-d-001 | 网络/网络延迟 | 对目标服务注入 100ms-3000ms 网络延迟，持续 30-120s | 网络延迟 |
| chaos-d-002 | 网络/网络丢包 | 对目标服务注入 10%-50% 网络丢包，持续 30-60s | 网络丢包 |
| chaos-d-003 | 网络/网络分区 | 隔离指定服务实例，阻断与其他服务的网络通信 | 网络分区 |
| chaos-d-004 | 网络/DNS故障 | 修改目标服务的 DNS 解析为错误地址 | DNS故障 |
| chaos-d-005 | 计算/CPU高负载 | 对目标容器或进程注入 CPU 满负载，占用 1-n 核 | CPU高负载 |
| chaos-d-006 | 计算/内存溢出 | 对目标容器或进程注入内存占用至指定水位（80%-95%） | 内存溢出 |
| chaos-d-007 | 计算/线程池耗尽 | 模拟线程池满，阻塞或拒绝新任务提交 | 线程池耗尽 |
| chaos-d-008 | 存储/磁盘IO | 对目标磁盘注入 IO 延迟或 IO 错误，持续 30-120s | 磁盘IO |
| chaos-d-009 | 存储/磁盘空间 | 向目标挂载点写入大文件，占满磁盘空间 | 磁盘空间 |
| chaos-d-010 | 进程/进程Kill | 强制 Kill 目标服务进程，观察自动拉起或主备切换 | 进程Kill |
| chaos-d-011 | 服务/服务熔断 | 触发服务熔断条件（持续超时/错误率上升），验证熔断后的降级行为 | 服务熔断 |
| chaos-d-012 | 服务/服务降级 | 模拟依赖服务不可用，触发下游降级逻辑 | 服务降级 |
| chaos-d-013 | 依赖/依赖故障 | 模拟外部依赖服务返回 500/503 或超时无响应 | 依赖故障 |
| chaos-d-014 | 依赖/超时注入 | 对指定调用链路注入调用超时（数据库、缓存、HTTP） | 超时注入 |
| chaos-d-015 | 数据/数据库故障 | 断开数据库连接、模拟主从切换或 SQL 超时 | 数据库故障 |
| chaos-d-016 | 数据/连接池耗尽 | 建立大量数据库连接至连接池上限，耗尽连接池 | 连接池耗尽 |
| chaos-d-017 | 缓存/缓存故障 | 停止 Redis/Memcache 服务、清空缓存或模拟缓存超时 | 缓存故障 |
| chaos-d-018 | 消息/消息队列故障 | 停止或延迟 MQ 消息发送/消费，模拟消息积压 | 消息队列 |
| chaos-d-019 | 配置/配置中心故障 | 停止配置中心服务，验证本地缓存兜底策略 | 配置中心故障 |
| chaos-d-020 | 安全/证书过期 | 模拟 HTTPS 证书过期或无效证书 | 证书过期 |

## containerized（容器化/K8s系统）

| 案例ID | 故障分类 | 注入方法 | 关联故障类型 |
|--------|---------|---------|-------------|
| chaos-c-001 | 容器/容器终止 | 随机 Kill Pod，验证 Deployment ReplicaSet 自动恢复 | 进程Kill |

| chaos-c-003 | 容器/网络延迟 | 对指定 Pod 注入网络延迟，验证 Service 负载均衡重试 | 网络延迟 |
| chaos-c-004 | 容器/网络丢包 | 对指定 Pod 注入网络丢包，验证优雅降级 | 网络丢包 |
| chaos-c-005 | 调度/Pod驱逐 | 模拟节点 NotReady，验证 Pod 漂移至其他节点 | 进程Kill, 网络分区 |
| chaos-c-006 | 存储/持久卷故障 | 模拟 PV 不可用或 NFS 存储挂载丢失 | 磁盘IO |
| chaos-c-007 | 配置/ConfigMap变更 | 动态修改 ConfigMap，验证应用热更新能力 | 配置中心故障 |
