## 保留规则

### SECURITY-01 非功能测试-安全

- 触发条件：材料中出现“非功能测试-安全”对应的能力、约束或改造。只凭规则标题、属性名称或附件示例不得判定命中。
- 必须分析：1.身份认证与授权漏洞；场景：越权访问（水平/垂直越权）；测试方法：；修改URL参数（如/user?id=123 → id=124）；使用低权限账号尝试高权限操作（如普通用户删除管理员数据）；验证点：；系统是否返回403错误或强制重新认证；敏感操作是否记录审计日志；2.注入攻击；场景：SQL注入、XSS、命令注入；测试方法：；输入' OR 1=1 --测试SQL注入；提交<script>alert(1)</script>测试XSS；输入; rm -rf /测试命令注入；验证点：；输入是否被转义或过滤（如输出编码、预编译SQL）；是否触发WAF拦截或日志告警；3.敏感数据泄露；场景：未加密传输或存储；测试方法：；抓包检查HTTPS是否全链路加密；检查数据库/日志中密码、身份证号是否明文存储；验证点：；敏感字段是否脱敏（如******）或加密（AES/SHA-256）；错误消息是否暴露堆栈信息（如数据库表名）；4.CSRF（跨站请求伪造）；场景：诱导用户触发非预期操作；测试方法：；构造恶意页面自动提交表单（如<form action="http://bank.com/transfer" method=POST>）；验证点：；关键操作（如转账）是否要求二次认证或CSRF Token；SameSite Cookie是否设置为Strict；5.文件上传漏洞；场景：上传恶意文件（如Webshell）；测试方法：；上传.php、.jsp后缀文件；修改Content-Type绕过检测（如image/png伪装）；验证点：；文件类型是否白名单校验（如仅允许.jpg/.png）；文件是否存储在非Web可执行目录；6.接口安全；场景：未鉴权的API访问；测试方法：；直接调用API（如/api/v1/users）不带Token；暴力枚举接口路径（如/api/v1/admin）；验证点：；是否返回401/403状态码；敏感接口是否限流（如每分钟10次）；7.配置错误；场景：默认密码、调试接口暴露；测试方法：；尝试admin/admin等默认凭证登录；访问/actuator/health等Spring Boot监控端点；验证点：；生产环境是否禁用调试接口；是否强制修改默认密码；8.业务逻辑漏洞；场景：重复提交、条件竞争；测试方法：；并发提交订单（如100次/s）测试重复支付；修改前端校验参数（如商品价格为负数）；验证点：；服务端是否幂等处理（如订单ID去重）；关键参数是否二次校验（如价格≥0）
- 最低覆盖：按详细设计与实际业务生成案例。每条案例包含：测试标题、前置条件、测试步骤、测试数据、预期结果、测试类型、优先级、备注。；仅覆盖材料证实且与本次改造相关的场景。
- 排除条件：材料未定义该能力，或本次改造与该能力无关时不适用；证据不足时记为 MISSING_EVIDENCE。
- 来源定位：【属性】非功能: / 非功能测试-安全。
- 证据来源：详细设计文档。
