# 数据、配置、权限与文件对象规约

## 数据规则

阶段 1 识别：输入来源、字段含义、计算/映射/汇总规则、唯一性、有效期、精度、落点、一致性要求、失败处理和证据。

## 配置/开关

阶段 1 识别：参数键、值域、默认值、生效范围、生效时机、动态刷新、组合关系、启停切换、异常值行为和证据。

## 权限/角色

阶段 1 识别：主体、角色、机构、资源、操作、数据范围、允许/拒绝规则、越权行为、审计要求和证据。

## 文件/报文

阶段 1 识别：文件/报文类型、命名、编码、格式、字段、大小/条数、校验、解析、错误反馈、输出结果、重复处理和证据。

本规约只用于识别事实、风险和 `designSignals`，不指定测试方法，不生成案例。
