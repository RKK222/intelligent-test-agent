# 业务改造-其它测试规则

## Agent 使用方式

本文件对应附件 7 行功能规约；仅合并同一测试对象下名称相同、检查行为相同的重复行，形成 7 个可执行规则卡。不同名称或不同检查目的不继续合并。

`objectRuleBindings` 必须评估 OTHER-01 至 OTHER-07。命中项记录材料证据、最低覆盖、Phase A 中间物项和案例引用；不命中项可按相同理由批量登记 `ruleIds`，但不得漏号。

规则中的固定值、产品名、表名和例子只是候选检查点；只有当前材料明确确认时才能写入预期，否则写“需确认”。混沌、性能、安全和生产安全三板斧等非功能规约已移至暂缓文件，当前案例设计与 Review 不加载。
