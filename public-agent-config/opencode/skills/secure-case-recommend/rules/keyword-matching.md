## 互斥关键词处理

以下关键词同时出现时，保留优先级高的，移除互斥的：

| 关键词 | 互斥关键词 |
|--------|-----------|
| SQL注入 | 输入验证 |
| 内部架构改造 | 逻辑绕过, 输入验证, XSS, SQL注入, 页面信息保护, URL跳转安全, 敏感信息展示, 隐私/敏感信息泄露, 错误处理, 页面信息保护 |
| 合作方 | 第三方 |

## 兜底策略

当 `kws` 为空时，推荐以下通用案例：

| 场景 | 案例描述 | 匹配关键词 |
|------|---------|-----------|
| A | 日志中不应存放客户敏感信息（口令、PIN、磁道信息、CVV等） | 敏感信息, 日志 |
| B | 本地存储敏感信息应采取访问控制机制 | 敏感信息, 存储 |
| C | 报错时不应返回系统/数据库/中间件版本信息 | 报错, 出错, 错误 |
