# Excel 处理协议

## 1. 强制提取

先将本技能目录解析为绝对路径 `SKILL_DIR`，再执行：

```bash
python "$SKILL_DIR/scripts/extract_excel.py" \
  <Excel文件1> <Excel文件2> \
  --output-dir work/excel --debug
```

后续主要读取：

- `workbook.json`：稀疏结构化结果，包含原始值、显示值、状态、格式、公式及隐藏信息；
- `tables/*.tsv`：工作表文本视图；超大稀疏表自动使用坐标表；
- `summary.md`：工作表状态、范围、表格模式和表头候选；
- `extract-report.json`：批量执行结果。

不得在脚本失败后绕过提取结果手工抄表。

## 2. 失败处理

测试数据 Excel 失败或结果明显异常时：

1. 查看 `extract-report.json` 中的文件、异常类型和位置；
2. 使用 `--debug` 重现；
3. 停止生成正式资产；
4. 将失败、影响和需要修复的能力写入转换报告；
5. 未经用户明确要求，不修改技能脚本，也不创建旁路脚本。

可选接口文档或测试案例 Excel 失败时，可以继续处理，但必须在转换报告中记录。

## 3. 读取要求

1. 不假设表头位于第一行，优先参考 `header_candidates`；
2. Sheet 名只能作为候选信号，必须结合表头、内容和代码读取路径判断角色；
3. 隐藏工作表、隐藏行、隐藏列和合并区域必须纳入分析；
4. 使用 `display_value` 还原账号、日期和格式化编号，使用 `value` 追溯原始存储值；
5. 区分缺失单元格、显式空字符串、公式空值和普通值；
6. 当 `table_mode=sparse` 时读取坐标 TSV，不得把远端单元格之间的空白区域生成大量空字段。
