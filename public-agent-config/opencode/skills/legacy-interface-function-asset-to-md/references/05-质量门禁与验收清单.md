# 质量门禁与验收清单

## A. 输入与 Excel

- [ ] 测试脚本和测试数据已成功配对；
- [ ] 必要 Excel 提取成功；
- [ ] `extract-report.json` 已检查，转换报告已写入提取状态和异常摘要；
- [ ] 隐藏 Sheet、隐藏行列、显示值和单元格状态已纳入分析；
- [ ] 超大稀疏表没有被展开成大量空字段。

## B. 输出粒度

- [ ] 同一 `interface_key` 只生成一个主 Markdown；
- [ ] 没有按数据行拆文件；
- [ ] 多主接口已拆分或说明；
- [ ] 每条测试数据已进入场景差异和预期信息，或有排除原因。

## C. 请求

- [ ] 请求字段、空值和嵌套结构完整；
- [ ] 静态字段使用输入中的具体值；
- [ ] 动态字段使用从代码还原的表达式；
- [ ] 没有 `${field_name}`、`${scenario.xxx}` 等通用占位符；
- [ ] 完整请求示例与场景差异可以重建全部场景；
- [ ] `i_seq_no` 仅在证明确为元数据时忽略差异。

## D. SQL、断言与 Mock

- [ ] 数据准备全部为 SQL；
- [ ] 非 SQL 动作已归入依赖，不得写成数据准备；
- [ ] 全部 Sheet 和代码来源均已扫描；
- [ ] SQL 无省略，并有阶段、场景和状态；
- [ ] 调用前 DELETE 未误标为恢复；
- [ ] 断言 actual、expected 和 operator 齐全；
- [ ] 数据库断言表包含完整的实际 SQL，且不含“执行状态”和“来源”列；
- [ ] Mock 未发现时没有写成“无上下游依赖”。

## E. 可信度与冲突

- [ ] 配置存在不等于实际执行；
- [ ] 文档没有覆盖代码执行事实；
- [ ] 缺少契约时写“未获取”，没有编造；
- [ ] 冲突没有静默消失；
- [ ] 低置信度语义匹配没有直接合并。

## F. 输出验证

- [ ] 固定输出目录 `<WORKSPACE_ROOT>/docs/功能模块/待确认` 已创建；
- [ ] “功能模块”作为字面目录名使用，没有替换成实际模块名称；
- [ ] 输入完整时，每个接口功能仅有资产和转换报告两个 Markdown；
- [ ] 未经用户明确要求，没有生成 ZIP、JSON、TSV 或其他交付文件；
- [ ] 模板固定章节完整；
- [ ] 没有残留 `{{templateVariable}}`；
- [ ] 没有省略号、“同上”或“类似场景”；
- [ ] GENERATED/MANUAL 标记成对；
- [ ] 正式资产和转换报告没有来源、路径、位置、指纹或证据输出；
- [ ] `scripts/validate_output.py` 返回成功；
- [ ] 转换报告记录验证结果。
