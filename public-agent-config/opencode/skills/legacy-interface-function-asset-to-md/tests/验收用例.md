# Skill 验收用例

## 用例 1：同一测试方法包含多条数据

- 只生成一个接口功能资产；
- 全部数据行进入场景差异和预期信息；
- 完整请求示例只写一次；
- 差异可重建每个场景。

## 用例 2：SQL 位于非标准 Sheet

- 扫描全部 Sheet；
- 不能因 Sheet 名不是“数据准备恢复”而忽略 SQL；
- 继续确认框架是否消费；
- 无法确认时标 `configured_unverified`。

## 用例 3：非 SQL 前置动作

- API、SSH、文件和方法调用不得标为数据准备；
- 归入“非 SQL 依赖动作”；
- 保留阶段、适用场景和状态。

## 用例 4：动态和静态请求字段

- 静态金额使用 Excel 具体值；
- 动态日期使用代码还原的表达式；
- 不出现 `${field_name}` 或 `${scenario.amount}`；
- 完整请求包含全部空值和嵌套字段。

## 用例 5：`i_seq_no` 的两种含义

- 有代码证据证明是 Excel 行号时，可忽略场景差异；
- 无证据或实际发送时，不得全局忽略；
- 实际发送的字段始终保留在完整请求。

## 用例 6：Java 和 Excel 都存在 SQL

- 两处 SQL 均保留；
- 分别判断执行状态；
- 数据库、参数或范围不同时生成冲突；
- 冲突输出不包含来源名称或位置；
- 不评价 SQL 安全性或数据积累风险。

## 用例 7：断言只在 Excel

- 搜索脚本和框架是否读取断言配置；
- 能确认则标实际断言；
- 不能确认则标 `configured_unverified`；
- 不生成不存在的 Java Assert。

## 用例 8：调用前 DELETE

- 标为前置清理；
- 不标为调用后恢复；
- 保留完整 SQL。

## 用例 9：接口文档缺失

- 仍基于脚本和测试数据生成资产；
- 无证据的字段含义、约束和版本写“未获取”；
- 不编造契约。

## 用例 10：输出验证

- 未替换模板变量导致验证失败；
- 省略号或通用场景占位符导致验证失败；
- 已删除章节再次出现导致验证失败；
- 任意来源、路径、位置、指纹或证据输出导致验证失败；
- 数据库断言缺少“实际 SQL”列，或包含“执行状态”“来源”列时验证失败；
- 完整、无省略的输出验证通过。

## 用例 11：固定输出目录

- 输出目录固定为 `<WORKSPACE_ROOT>/docs/功能模块/待确认`；
- “功能模块”是写死的目录名，不替换成实际模块；
- `待确认` 不存在时先创建；
- 输入完整且只有一个主接口时，只生成资产和转换报告两个 Markdown；
- 多个主接口时，每个接口各生成两个 Markdown；
- 最低输入不完整时只生成转换报告；
- 未经用户明确要求，不生成 ZIP、JSON、TSV 或其他交付文件；
- 其他目录中的同名文件不自动覆盖、移动或删除。
