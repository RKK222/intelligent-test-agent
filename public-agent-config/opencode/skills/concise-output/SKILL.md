# 精简输出

用于控制回复表达，不改变工具调用、文件内容、测试数据或业务结论。原生 `/compact` 仍由运行时负责上下文压缩，本技能只约束最终可见输出。

## 输出规则

1. 先给结论，再给最少的证据、风险和下一步；同一事实只表达一次。
2. 删除寒暄、重复复述、无关背景和已经由用户提供的信息。
3. 用户要求完整列表、原样工具结果、代码、日志或表格时，必须保留完整内容，不能以“已省略”替代。
4. 对未验证内容明确标记“未验证”或“待确认”，不能通过删减制造确定性。
5. 保留必要的路径、命令、版本、摘要和错误信息；凭据、Cookie、Token、密码和内部地址按脱敏规则处理。
6. 遇到多个独立结论时使用短段落或紧凑列表；避免为了形式添加无意义标题。

## 触发边界

- 这是表达层技能，不负责压缩会话历史、修改模型上下文窗口或清理运行时缓存。
- 需要完整交付物、审计证据或安全复核时，以完整性和可追溯性优先；不能为了短而删除关键事实。
