# 对话与上下文

右侧对话区用于发起测试任务、查看执行过程和处理 Agent 的交互请求。第一条消息发送时会自动创建主对话。

## 对话到底怎么建？

正常流程不需要先建会话：选中应用和 workspace、确认 TestAgent 服务可用后，在输入框写任务并点击发送，系统会在发送时自动创建主对话并把第一条消息作为标题来源。

右侧输入卡片的“新建对话”图标用于主动清空当前草稿、开始另一条对话。它不会删除历史对话，也不会取消后台已经运行的任务；历史对话仍可从历史入口找回。

## 怎样写清楚任务

一条可执行的任务通常包含四部分：

1. 测试对象：哪个需求、接口、模块或文件。
2. 动作：分析、设计案例、执行测试、修复问题或审核结果。
3. 约束：使用哪些材料、目录、格式或测试方法。
4. 产物：结果写到哪里，需要哪些文档或代码。

## 安排夜间执行

算力紧张时，可以把任务安排在北京时间晚上 9 点到次日早上 7 点异步启动：

1. 先在当前消息框写好任务，并按需添加 Agent、模型、文件或需求子条目。
2. 点击发送按钮左侧的定时图标。
3. 在 15 分钟启动时段中选择一个时间。系统会根据全局名额自动标出推荐时段；显示“已满”的时段不能选择。
4. 确认后等待“已安排”提示。只有提交成功后，草稿和上下文附件才会清空。

当前已经打开历史对话时，任务会在该对话继续；处于全新空白对话时，系统会为任务预留一条新对话。弹层不再单独询问执行位置。

点击对话栏顶部的“会话列表”，在左侧浮层中切换到“待执行任务”，页面会立即刷新并分页收齐自己所有尚未启动的夜间任务。当前对话的任务排在最前，其余按启动时段排序。任务卡会显示内容预览、启动时段、创建时间、状态以及发生过的顺延次数；任务仍为“待执行”时可以改期或取消，进入“正在启动”后不能再改期或取消。取消前需要在卡片内再次确认。

已有对话安排夜间任务后，在任务取消、最终失败或成功启动前，当前对话不能继续发送普通消息，也不能归档；“新建对话”仍可使用，可以先处理别的工作。任务启动后直接复用普通对话的执行过程和结果展示，用户消息旁会显示“夜间定时执行”和北京时间的实际启动时间。如果窗口内始终无法启动，当前对话会显示失败卡；关闭失败卡不会重新执行任务。

夜间任务已经启动后，如果模型在根会话返回错误，平台会自动尝试撤销并重发最后一条用户消息，最多 3 次，分别等待约 1、2、4 分钟。
等待时消息旁显示“自动重发 n/3”和倒计时，对话输入会暂时锁定；替代消息开始后，旧回答、工具过程和文件改动会按原生回退语义移除。
第三次仍失败时保留最新失败轮次和“3/3”标识。自动重发不会由手动操作重置。

普通对话或夜间对话的最后一条用户消息，在运行已经结束且仍可安全恢复时会显示“撤销重发”。平台接受请求后状态栏立即进入运行中，旧回答、工具过程、Todo 和 Diff 同时从页面隐藏，但原用户消息保留在原位置；如果原生回退开始前失败，旧内容会恢复，否则随后由新结果继续展示。
平台使用新的消息标识重新执行，旧回答不会继续进入模型上下文；运行中、子 Agent、较早消息或缺少远端边界时不显示该入口。OpenCode 自身的短时“重试中”只表示模型供应商重试，
页面会展示状态但不会因此重复发送消息。

## 批量生成子条目测试案例

鼠标移入右侧输入卡片，或把光标放进输入框后，卡片上沿会显示“批量生成子条目测试案例”图标。点击后可在页面弹层中一次选择多个当前 workspace 的需求子条目：

1. 列表与输入框键入 `#` 时完全相同，可按需求项或子条目名称搜索，也可全选；一批最多选择 50 项。
2. 底部要求默认为“请生成子条目测试案例。”，可以修改；系统会自动为每项补充需求项和子条目名称。
3. 选择“立刻执行”时，每个子条目都会建立一条独立对话并立即运行，不会切换或清空当前对话。
4. 选择“定时执行”时，可以勾选多个可用夜间时段，系统按子条目顺序轮流分配；超级管理员还可添加未来 24 小时内的多个整分钟测试时间。夜间总剩余名额不足时不能提交。
5. 点击“立刻执行”或“定时执行”后，弹层会立即切换到不可编辑的“会话创建情况”页，不能再次提交同一批次；每行会显示资料加载、会话创建、启动或任务创建结果。
6. 创建情况页不会自动关闭。其他条目不会因为单项失败而停止；失败项可单笔重试，也可批量重试全部失败项，重试会沿用本次批量身份和已经创建的会话。
7. 创建或重试期间不能关闭。处理结束后由你主动关闭；若还有条目没有创建会话，页面会先确认是否结束本次批量创建。确认关闭后本批次结束，再次打开时选择为空且要求恢复默认值。

每个子条目会读取 `#` 候选聚合出的需求、设计、编码和测试阶段文件。二进制文件会跳过；无可读文件、读取失败或内容超限的条目不会创建对话。批量资料使用独立上下文，不会出现在当前输入框的附件区。

## 添加上下文

- `@Agent`：选择当前运行态已经加载的 Agent。双语模板候选项以中文名为主、英文名为辅，选择后仍插入稳定的 Agent 英文技术 ID。
- `/Skill`：选择当前 Agent 可用的 Skill。双语模板候选项同样以中文名为主、英文名为辅，选择后仍插入稳定的 Skill 英文技术 ID。
- `@文件`：选择工作区文件并作为显式上下文加入本轮消息。
- `#需求子条目`：只解析 `spec/<需求项>/<阶段>/<子条目>` 结构，按同名子条目聚合需求、设计、编码和测试阶段文件；工作区根目录下的旧需求结构不会进入候选。
- 小地球引入：先在左侧“工作空间”标题右侧点击小地球，从外部需求页面引入子条目；返回后再用 `#` 选择，避免只把单个阶段文件漏带进任务。
- 编辑器选区：把当前选中的代码或文本加入下一轮消息。
- Git hunk：从差异视图引用当前变更片段。

通过聊天附件按钮选择的文件会先保存到当前个人工作区：内容和扩展名一致的文件自动复用，文件内容变化时保留新版本，不覆盖历史对话引用。文本和代码由 OpenCode 原生读取；图片、PDF、音频和视频会根据当前模型能力决定是否原生读取；Excel、Office、压缩包及模型不支持的媒体交给工作区工具处理。附件较多时页面只折叠展示，不会减少本轮实际关联的文件。

新建或修改 Agent/Skill 定义后，平台会自动热加载当前用户目录；重新输入 `@` 或 `/` 会按最新目录给出候选。`@` 遵循 OpenCode 原生子智能体口径，只列出 `subagent`/`all`，因此默认 `primary` Agent 不在其中；`/` 只列出 OpenCode 已识别且当前 Agent 有权使用的 Skill。

## 处理中可以做什么

- 当前 Run 忙碌时继续发送的 Prompt 会进入跟进队列。
- Agent 出现权限卡时，按本次允许、始终允许或拒绝作出选择。
- Agent 出现提问卡时填写答案，提交后原卡片会收敛为完成态。
- 需要终止时使用停止按钮；只有 Run 已创建并处于运行态时可以终止。

## 小宠物旁路问答

主对话至少发送过一条消息后，点击小宠物会基于当前主 Session 创建临时上下文，不写入主对话历史，适合追问“刚才做了什么”“为什么失败”。

小宠物提供寻迹鹿、巡查红熊猫、深夜龙、星探狐、稳态熊猫、工具浣熊和夜巡猫七种图片形象。打开宠物浮层后，点击标题栏的脚印按钮可以选择显示方式：

- 每日轮换：按本地日期依次更换值班伙伴。
- 每天随机：每天抽取一个伙伴，当天保持不变。
- 自主选择：固定使用自己选中的伙伴。

在同一处可以用“宠物大小”滑杆调整显示比例（75%–250%，默认 150%）。比例保存在当前浏览器，旧版本没有该设置时按 150% 显示。

显示偏好只保存在当前浏览器，不会影响旁路问答内容，也不会同步到其他设备。

帮助中心中的“小宠物问答”会携带当前手册章节，适合询问按钮含义和操作顺序。没有主对话时，只要已经选择工作区且 TestAgent 服务可用，小宠物就会创建独立的内部手册问答 Run；它不会创建普通聊天会话，也不会把问题或答案写入主对话历史。

## 会话列表

点击对话栏顶部的“会话列表”，会在对话栏左侧打开非模态浮层，主对话仍完整可见。浮层中的“会话”页可以搜索和连续切换已有 Session，当前会话会高亮；选择后浮层不会自动关闭，便于继续查找。再次点击“会话列表”、点击关闭按钮、按 Esc 或收起整个右侧对话栏时会关闭浮层。

切换尚未完成时不要重复发送消息；只读历史会明确显示原因。新建对话只清理当前草稿，不会删除历史 Session。
