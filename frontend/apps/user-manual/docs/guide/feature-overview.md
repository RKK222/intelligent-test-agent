# 功能总览

第一次使用，先看[快速开始](./getting-started.md)。如果只是想找某个入口，这一页更方便；页面空白、按钮点不了或操作失败时，去看[常见问题与排查](./faq.md#遇到故障怎么查)。

## 工作台区域

| 区域 | 主要入口 | 能做什么 |
| --- | --- | --- |
| 顶部栏 | 应用、工作空间、版本、通知铃铛、用户手册、资源与头像 | 切换工作上下文、查看分享通知、打开帮助中心，以及查看账号角色和进程状态、重启自己的 TestAgent 进程 |
| 左侧活动栏 | 编辑器、工具盒子、长期记忆、Agent / Skill / MCP / Tool Hub、系统管理、设置 | 切换主要工作模式；系统管理对应用管理员仅显示应用 Git 刷新，超级管理员保持完整菜单 |
| 左侧文件区 | 工作空间、Agents、变更 | 浏览和维护文件、查看 Agent/Skill 配置、处理当前个人 worktree 的 Git 变更 |
| 中央编辑区 | 文件标签、源码编辑、Markdown/思维导图预览、Diff | 编辑文件、预览文档和思维导图、检查变更和处理冲突 |
| 右侧对话区 | 主对话、任务消耗、会话列表、协作分享、待执行任务、原始输出 | 发起任务、查看耗时和记忆使用情况、与同事共用一条会话、恢复历史会话、管理定时任务、查看当前页面捕获的调试报文 |
| 底部抽屉 | Run、终端 | 查看运行过程，或在当前工作区上下文中使用终端 |

应用、workspace 或版本一变，文件树、Git 变更和对话上下文也会跟着变。切换前先保存正在编辑的文件，免得把上一个应用的页面状态误当成当前数据。

点击“工作台”仍会直接回到编辑器，不产生页面 Tab。点击工具盒子、长期记忆、能力库或系统管理功能后，中央区域顶部会出现应用内页面 Tab；继续点击其它功能会新增 Tab，重复点击同一功能只会切换到已有项。控制台的定时任务、运行管理、通用参数等二级功能也各自占用一个 Tab，应用管理员仍只能打开配置管理。

页面 Tab 可以点击切换、拖动排序，或在聚焦后用方向键切换；按 `Ctrl+Shift+←/→` 可排序，按 `Delete` 可关闭。每个 Tab 都有关闭按钮，右键还可以关闭当前、其他、左侧、右侧或全部；右上角列表按钮用于定位已打开页面，垃圾桶按钮用于关闭全部。关闭活动项后优先进入右边一项，没有右边项时进入左边一项；关闭最后一项会自动回到工作台。

从功能页切回工作台不会关闭已打开页面，再次点击相应入口可继续原来的筛选、分页或滚动位置。刷新只恢复当前用户的 Tab 清单、顺序和活动项，页面数据会重新安全加载；浏览器前进、后退也只切换或补开历史目标，不会清空其它 Tab。API Key 明文、内部模型 Token 和临时问题排查授权不会随 Tab 保存，离开对应页面时会立即清理。

## 文件与编辑器

- 工作区文件树支持新建、上传和多选，也能复制、剪切、粘贴、移动或删除。文件能不能改，取决于当前角色、目录类型和后端权限。
- 纯引用文件和目录只读；工作区与引用合并形成的目录可以向工作区侧新增内容，但不能整体重命名或删除。
- 大型 UTF-8 文件超过一次性读取阈值后使用渐进式只读预览，可继续加载一段或确认后加载全部。
- Markdown 文件底部有预览按钮。单击打开整体预览，双击进入源码与预览分屏；再操作一次就会回到纯编辑模式。
- Markdown 中的 Mermaid `flowchart`、`graph`、`sequenceDiagram`、`stateDiagram` 和 `stateDiagram-v2` 代码块可点击“可视化编辑”。只有点击“应用到 Markdown”后，画布修改才会写回当前文档；无法安全解析的语法应回到源码模式修改。
- Markdown 中的 `mind` 代码块默认显示源码，可切换“预览”，或点击“编辑”在弹层里改名、增删/拖动节点、撤销重做、缩放折叠并调整常用样式。点击“应用思维导图”只更新当前代码块，仍需再保存 Markdown 文件；取消不会改变原文。
- 独立 `.mind` 文件打开后默认在中央显示思维导图。可写的小文件可从底部点击思维导图按钮进入编辑；编辑草稿会显示未保存星号，必须先“应用”或“取消”才能保存文件。只读引用、渐进式大文件或元数据损坏时只能安全预览。
- 首次应用会为节点补充稳定编号，并把折叠、颜色、边框、形状、字号等画布属性写入单独的紧凑 Markdown 注释；以后新增节点不会复用已经删除的编号。支持的原始格式是一个 `#` 根标题和无序层级列表，不支持 Tab 缩进、有序列表、富文本、图片、链接、标签、概要或自由坐标。
- 思维导图画布使用 SimpleMindMap `0.14.0-fix.3`，该第三方项目采用 MIT License；运行所需资源随前端制品提供，企业环境查看或编辑时不访问公网。
- 打开“实时追踪”后，Agent 写文件时会自动预览最近的变化。关掉以后，文件树和 Git 变更照常刷新，只是不再自动打开文件。
- 需要把测试资料带到关联的外部页面时，可以在文件树中选择一个或多个“测试设计”文件，或者“测试执行”文件和目录，再点击工作空间标题右侧带数量的纸飞机按钮。平台会打开新标签页，不会移动或删除原文件。

文件和 Git 的详细规则见[应用版本与个人工作区](./workspace.md)。

## 对话、上下文与任务

- 工作区和 TestAgent 服务可用后，直接发送第一条消息即可自动创建主对话。
- 输入 `@` 可选择 Agent 或文件，输入 `/` 可选择 Skill，输入 `#` 可选择已引入的需求子条目；编辑器选区和 Git hunk 也可以作为上下文。
- 当前 Run 忙碌时继续发送的 Prompt 会进入跟进队列；权限卡和提问卡需要在当前会话中处理。
- 定时入口支持北京时间 21:00 至次日 07:00 的夜间任务；待执行任务可在“会话列表 → 待执行任务”中查看、改期或取消。
- 输入卡悬浮或聚焦后可打开批量生成入口，最多选择 50 个与 `#` 同源的需求子条目；打开定时选择会隐藏立即执行，选中有效时间后才显示定时执行，也可用右上角关闭图标返回立即模式。提交后进入不会自动关闭的会话创建情况页，每项生成独立对话并可立即执行或分配到多个定时时间，失败项可单笔或批量重试且不改变当前草稿和附件。主动关闭会结束本批次，存在未创建会话的条目时需要确认，再次打开从全新选择开始。
- 已有会话可以分享给指定同事，并逐人设置“只读”或“可对话”。链接只对名单内的用户生效；可对话成员在同一会话和工作区继续处理任务，页面会标明消息是谁发的。
- 分享保存后，被分享人会在顶部通知铃铛中收到提醒；通知默认先显示未读，点击有效通知会在新标签页打开分享会话。会话真正打开成功后，通知才会变为已读。
- 会话列表可以恢复历史会话，也可以用图钉把常用会话放在前面。“分享给我”页签集中显示别人分享的会话；还在运行或等待交互的会话会带上状态或提醒标记。
- 对话底部“任务消耗”会持续显示本轮累计耗时，并在有数据时同时显示 Token；任务结束后耗时仍会保留。成功结果只有实际使用长期记忆时才显示“参考了 N 条记忆”。
- “原始输出”记录当前页面捕获到的 HTTP 请求、响应正文和 RunEvent SSE 数据，敏感内容会先脱敏。可以按关键词筛选，也可以下载；排查问题时，把里面的 `traceId`、`runId` 和报错现象一起发给管理员。

具体操作见[对话与上下文](./conversation.md)。

## 长期记忆

- 左侧活动栏的“长期记忆”分为“我的记忆、团队记忆、Skill 提案”。个人记忆可以只用于当前应用，也可以提升为本人所有应用通用。
- 符合开放条件的成功任务可能自动形成当前应用的个人记忆；团队记忆只能由成员手工提交，并由应用管理员审核后生效。
- 记忆详情会展示来源会话和 Run 标识。原始聊天仍留在原会话中，只有会话所有者可以打开全文。
- 已生效的记忆可以进一步发起 Skill 提案；审核生成的草稿仍要到 Skill Hub 完成 Git 和发布流程。

适用范围、暂停和归档规则见[长期记忆](./memory.md)。

## Git 变更与受控助手

工作区的“变更”页分成应用工作空间、应用 Agent 和公共 Agent。你可以按权限查看差异、暂存、取消暂存、回退或提交。保存只是把内容写进个人 worktree，不等于发布；页面明确显示推送成功后，允许发布的内容才会进入远端。

当前 workspace 标题栏“…”中的“刷新文件树”只重新读取磁盘，“拉取远程”才会为当前用户的整棵个人 worktree 执行 Git fetch 和 merge。拉取可能同时更新同一 worktree 中的其它 workspace 目录和应用 Agent，但不会修改其他用户。

如果 `@` 候选中有 `workspace-git-assistant`，可以让它检查状态、拉取、暂存、回退或提交，也能预览发布和处理冲突。它走的还是页面背后那套平台 Git 能力，绕不过目录角色、owner、`spec/**` 禁发布和冲突规则。执行写操作前，先看清它列出的文件和影响范围。

## Agent、Skill、MCP、Tool 与 Hub

- 左侧 Agents 区维护公共和应用 Agent/Skill。公共配置只有超级管理员可写；应用配置只有应用管理员和超级管理员可写。
- 新建或修改 Agent/Skill 后，平台会在当前任务空闲时热加载本人运行态；`@` 只列出可作为子智能体调用的 Agent，默认 `primary` Agent 只出现在主 Agent 选择器。
- 公共、应用或个人应用配置的 dispose 状态会进入通知中心；等待、成功、失败和被替代使用同一条通知持续更新，失败状态可受控重启本人进程。
- 左侧活动栏的“Agent / Skill / MCP / Tool Hub”用于发现所有应用已推送的 Agent/Skill 快照，并查看当前已经加载的 MCP 与 Tool。MCP/Tool 是运行态只读目录，不参与发布和引用。
- 点击能力卡会从右侧打开详情；拖动详情左边缘可以调宽，标题栏的全屏按钮可进入或退出页面内全屏。
- 有管理权限的用户可以把本应用最新推送的能力发布到 Hub，也可以把别处已经发布的能力引用到当前个人 worktree。引用、取消引用和更新之后，都要回到 Git Changes 检查并 push；否则只改了本地。
- “待更新”会把来源的新版本合入当前个人 worktree；存在文本或二进制冲突时，先在 Hub 的冲突界面选择处理方式，再完成 Git 提交和推送。

配置文件操作见[Agent 与 Skill 配置](./agent-config.md)。

## 应用资产引用

应用管理员和超级管理员可以从工作台底部打开“引用配置”，把应用资产库里已经同步的橙色 SDD 根目录接入个人工作区。资产文件不会复制进个人 Git。文件树会按合并目录或参考别名显示这些只读内容，引用文件也能加入对话。

资产库初始化、跨服务器同步、Git 指针核验、JSONC 更新和只读边界见[引用配置](./reference-config.md)。

## 小宠物与帮助中心

- 顶部书本图标和首页入口都可打开内置用户手册，本地全文搜索不依赖公网；手册打开期间顶部入口保持红色选中态。
- 已有主对话时，小宠物追问当前 Session 的临时上下文；没有主对话时，只要工作区和服务可用，就依据当前用户手册章节回答，不创建普通对话。
- 宠物浮层可选择七种伙伴、每日轮换、每天随机或固定角色，并调整显示大小；这些偏好只保存在当前浏览器。
- 宠物浮层标题栏的小手柄可进入俄罗斯方块、扫雷、数独和贪吃蛇。小游戏不依赖主 Session，也不会写入工作区或对话历史。
