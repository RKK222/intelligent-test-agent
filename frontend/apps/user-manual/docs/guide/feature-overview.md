# 功能总览

本页按当前工作台真实入口汇总主要能力。第一次使用建议先完成[快速开始](./getting-started.md)；遇到页面空白、按钮不可用或操作失败时，直接查看[常见问题排查](./troubleshooting.md)。

## 工作台区域

| 区域 | 主要入口 | 可以完成什么 |
| --- | --- | --- |
| 顶部栏 | 应用下拉、用户头像、用户手册 | 切换应用、查看账号角色和进程状态、打开帮助中心 |
| 左侧活动栏 | 编辑器、Agent 与 Skill Hub、系统管理、设置 | 切换主要工作模式；系统管理只对超级管理员显示 |
| 左侧文件区 | 工作空间、Agents、变更 | 浏览和维护文件、查看 Agent/Skill 配置、处理当前个人 worktree 的 Git 变更 |
| 中央编辑区 | 文件标签、源码编辑、Markdown 预览、Diff | 编辑文件、预览文档、检查变更和处理冲突 |
| 右侧对话区 | 主对话、会话列表、待执行任务、原始输出 | 发起任务、恢复历史会话、管理定时任务、查看当前页面捕获的调试报文 |
| 底部抽屉 | Run、终端 | 查看运行过程，或在当前工作区上下文中使用终端 |

切换应用、workspace 或版本时，文件树、Git 变更和对话上下文会一起切换。操作前先保存未保存内容，不要把上一应用的页面状态当成当前工作区的数据。

## 文件与编辑器

- 工作区文件树支持新建、上传、多选、复制、剪切、粘贴、移动和删除；是否可写由当前角色、目录类型和后端权限共同决定。
- 纯引用文件和目录只读；工作区与引用合并形成的目录可以向工作区侧新增内容，但不能整体重命名或删除。
- 大型 UTF-8 文件超过一次性读取阈值后使用渐进式只读预览，可继续加载一段或确认后加载全部。
- Markdown 文件底部提供预览按钮：单击进入整体预览，双击进入源码与预览分屏，再次操作可返回纯编辑模式。
- Markdown 中的 Mermaid `flowchart`、`graph`、`sequenceDiagram`、`stateDiagram` 和 `stateDiagram-v2` 代码块可点击“可视化编辑”。只有点击“应用到 Markdown”后，画布修改才会写回当前文档；无法安全解析的语法应回到源码模式修改。
- 开启“实时追踪”后，Agent 写入文件时会自动打开最近变化的只读预览；关闭后仍会刷新文件树和 Git 变更，只是不再自动打开文件。

完整文件与 Git 规则见[应用版本与个人工作区](./workspace.md)。

## 对话、上下文与任务

- 工作区和 TestAgent 服务可用后，直接发送第一条消息即可自动创建主对话。
- 输入 `@` 可选择 Agent 或文件，输入 `/` 可选择 Skill，输入 `#` 可选择已引入的需求子条目；编辑器选区和 Git hunk 也可以作为上下文。
- 当前 Run 忙碌时继续发送的 Prompt 会进入跟进队列；权限卡和提问卡需要在当前会话中处理。
- 定时入口支持北京时间 21:00 至次日 07:00 的夜间任务；待执行任务可在“会话列表 → 待执行任务”中查看、改期或取消。
- 会话列表支持恢复历史 Session。历史会话如果仍在运行或等待交互，会显示运行态或提醒标记。
- “原始输出”只展示当前页面生命周期内捕获并脱敏的 HTTP 请求/响应正文和 RunEvent SSE 数据，可按关键词筛选和下载，适合把 `traceId`、`runId` 与错误现象一起交给管理员。

完整操作见[对话与上下文](./conversation.md)。

## Git 变更与受控助手

工作区的“变更”页区分应用工作空间、应用 Agent 和公共 Agent。可以按权限查看差异、暂存、取消暂存、回退、本地提交或提交并推送。保存文件不等于已经发布；只有页面明确显示推送成功，远端才获得允许发布的内容。

当前 workspace 标题栏“…”中的“刷新文件树”只重新读取磁盘，“拉取远程”才会为当前用户的整棵个人 worktree 执行 Git fetch 和 merge。拉取可能同时更新同一 worktree 中的其它 workspace 目录和应用 Agent，但不会修改其他用户。

如果 `@` 候选中显示 `workspace-git-assistant`，可以在对话中让它检查状态、拉取、暂存或取消暂存、逐文件回退、提交、发布预览、发布和处理冲突。它调用的仍是页面同一套平台 Git 能力，不能绕过目录角色、owner、`spec/**` 禁发布或冲突规则；执行写操作前应核对它展示的目标文件与影响范围。

## Agent、Skill 与 Hub

- 左侧 Agents 区维护公共和应用 Agent/Skill。公共配置只有超级管理员可写；应用配置只有应用管理员和超级管理员可写。
- 新建或修改 Agent/Skill 后，平台会在当前任务空闲时热加载本人运行态；`@` 只列出可作为子智能体调用的 Agent，默认 `primary` Agent 只出现在主 Agent 选择器。
- 左侧活动栏的“Agent 与 Skill Hub”用于发现所有应用已推送的 Agent/Skill 快照，查看原创应用、文件和依赖。
- 具备管理权限的用户可以把本应用最新推送的能力发布到 Hub，也可以把已发布能力引用到当前个人 worktree。引用、取消引用和更新都要回到 Git Changes 检查并成功 push 后，才对应用远端正式生效。
- “待更新”会把来源的新版本合入当前个人 worktree；存在文本或二进制冲突时，先在 Hub 的冲突界面选择处理方式，再完成 Git 提交和推送。

配置文件操作见[Agent 与 Skill 配置](./agent-config.md)。

## 应用资产引用

应用管理员和超级管理员可从工作台底部打开“引用配置”，把应用资产库中已同步的橙色 SDD 根目录加入当前个人工作区。资产文件不会复制进个人 Git；文件树以合并目录或参考别名展示只读内容，并允许把引用文件加入对话。

资产库初始化、跨服务器同步、Git 指针核验、JSONC 更新和只读边界见[引用配置](./reference-config.md)。

## 小宠物与帮助中心

- 顶部问号和首页入口都可打开内置用户手册，本地全文搜索不依赖公网。
- 已有主对话时，小宠物追问当前 Session 的临时上下文；没有主对话时，只要工作区和服务可用，就依据当前用户手册章节回答，不创建普通对话。
- 宠物浮层可选择七种伙伴、每日轮换、每天随机或固定角色，并调整显示大小；这些偏好只保存在当前浏览器。
- 宠物浮层标题栏的小手柄可进入俄罗斯方块、扫雷、数独和贪吃蛇。小游戏不依赖主 Session，也不会写入工作区或对话历史。
