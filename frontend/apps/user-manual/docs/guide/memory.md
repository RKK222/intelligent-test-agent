# 长期记忆

长期记忆用于保存可以反复使用的偏好和经验，例如“回答时先给结论”或“缺陷结论要附带复核证据”。后续任务符合使用范围时，系统可以自动参考这些内容，不必每次重新说明。

入口在工作台左侧活动栏，名称为“长期记忆”。如果页面提示“记忆能力尚未对当前账号开放”，说明当前账号还没有加入开放范围，不影响原有对话和任务执行。

## 什么时候会形成或使用记忆

- 账号已开放记忆能力、当前应用明确，并且人工发起的主任务成功结束后，系统可能从本轮对话中提炼可复用的信息。并不是每次对话、每句话都会变成记忆。
- 自动学习形成的个人记忆默认只用于当前应用，并直接进入“已生效”状态。也可以在记忆中心手工添加。
- 新任务开始前，系统会在已生效的个人全局记忆、当前应用个人记忆和当前应用团队记忆中查找相关内容。
- 只有某条记忆实际用于本轮任务时，完成结果旁才会显示“参考了 N 条记忆”。没有这行文字，只表示本轮没有使用记忆，不能据此判断服务异常。

长期记忆只保存提炼后的内容和来源引用，原始聊天仍保留在原会话中，不会复制到记忆库。

## 三个页签分别做什么

| 页签 | 使用范围 | 主要操作 |
| --- | --- | --- |
| 我的记忆 | 仅本人；可选择所有应用或当前应用 | 添加、编辑、查看证据、提升为个人全局、暂停、归档 |
| 团队记忆 | 当前应用成员 | 提交候选；应用管理员审核后才对团队生效 |
| Skill 提案 | 当前应用成员 | 把已生效记忆整理为 Skill 草稿，再进入 Skill Hub 完成发布 |

“团队记忆”和“Skill 提案”都以当前应用为边界。页面提示“先选择一个 Application”时，先回到顶部选择应用，再重新进入相应页签。

## 管理个人记忆

1. 打开“我的记忆”，点击“添加个人记忆”。
2. 填写需要长期复用的信息或偏好，最多 2000 字。
3. 选择“所有应用”或“当前应用”，保存后在卡片上核对适用范围和状态。
4. 点击卡片或“查看证据”，可以查看来源会话、Run 标识、生效时间和最近变更。只有原会话所有者可以打开完整对话，其他有权查看记忆的人只能看到安全的来源摘要和标识。

当前应用范围的个人记忆可以“提升为个人全局”，之后会用于本人的其它应用。点击“暂停使用”后，该记忆不再进入新任务；点击“归档”后也不再使用，但记录仍会保留，便于追溯。

如果卡片只显示治理摘要，并提示正文暂时不可用，页面会暂时禁用编辑和“提交为团队记忆”。点击“刷新”，等完整正文恢复后再继续，不要把摘要当作完整内容重新保存。

## 提交和审核团队记忆

普通应用成员可以用两种方式提交：在“团队记忆”页点击“提交团队记忆”，或从一条已生效的个人记忆详情中点击“提交为团队记忆”。提交后先进入待审核状态，不会立即影响其他成员。

应用管理员在详情中批准后，记忆才会成为当前应用的团队记忆；拒绝时必须填写原因，便于提案人修订。即使提交人本身是应用管理员，也不能跳过审核。团队记忆不会从普通对话自动生成。

## 从记忆沉淀为 Skill

1. 打开一条“已生效”的个人或团队记忆详情，点击“沉淀为 Skill”，填写标题。
2. 提案经应用管理员批准后，系统生成可编辑的 `SKILL.md` 草稿。
3. 在“Skill 提案”中编辑并保存草稿。这里的保存不会自动写入工作区，也不会提交或发布。
4. 点击“前往 Skill Hub 发布”，沿用现有的检查、Git 提交和发布流程完成交付。

归档 Skill 提案只会结束这条提案，不会撤回已经发布的 Skill。
